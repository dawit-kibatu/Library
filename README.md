# Library
Library App

A simple book tracking app built with HTML, CSS, and JavaScript for The Odin Project.

Live Demo:-https://dawit-kibatu.github.io/Library/
What It Does

    Add books with title, author, pages, and read status

    Toggle books as read/unread

    Remove books from your library

    Saves your books locally (no account needed)

How to Use

    Click "NEW BOOK"

    Fill out the form

    Click "ADD"

    Manage books with the buttons on each card

Tech Used

    HTML

    CSS

    JavaScript

Made for The Odin Project
